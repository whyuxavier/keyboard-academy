# Keyboard Academy

Тренажер клавіатури: сліпий друк (ЙЦУКЕН і QWERTY), швидкість друку, комбінації клавіш, знайомство з клавіатурою та життєві сценарії. HTML + CSS + JavaScript без фреймворків, PWA, працює офлайн.

## Запуск
- GitHub Pages: залийте вміст папки в репозиторій і увімкніть Pages (гілка `main`, корінь).
- Локально: `python3 -m http.server` у цій папці й відкрийте `http://localhost:8000` (з `file://` модулі не працюють).

## Структура
- `js/core` — логіка (сховище, розкладки, клавіатура, набір тексту, статистика, PWA)
- `js/content` — уроки, тексти, комбінації, клавіші, сценарії (легко доповнювати)
- `js/views` — сторінки
- `sw.js` — офлайн-кеш. Після змін файлів збільшуйте `VERSION`.
